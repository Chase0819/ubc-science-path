# UBC Science Path

Unofficial site for UBC first-year Science students:

1. **Grade calculator** — component weights, sessional average, letters, 4.33 GPA
2. **Course planner** — eligibility courses for BSc specializations
3. **Major outlook** — local statistical model vs 2022–2026 published cutoffs

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Data follows UBC Science specialization requirement and historical admission pages for the 2026 cycle. Confirm everything against the Faculty of Science before you register or apply.
